## Laravel Azterketa - 2425-DWS-Exam
## Azterketaren argibideak
Repo hau azterketaren oinarria da. 
Arretaz irakurri beheko pauso guztiak hasi aurretik.
## Prestaketa
Klonatu zure azterketaren repositorioa
Terminalean exekutatu:
- git clone https://github.com/2425-DWS-Exam/exam_erronkak.git
- cd exam_erronkak
## Laravel-en menpekotasunak instalatu
- composer install
- cp .env.example .env
- php artisan key:generate
## Datu-basea sortu
Sortu zure tokiko MySQL zerbitzarian examen_erronkak izeneko datu-basea.
.env fitxategian eguneratu datu-basearen datuak (host, erabiltzailea, pasahitza).
## Azterketa egiteko
Aldaketak egin behar dituzun fitxategietan lan egin.
Modeloak, kontrolatzaileak, bideak, edo ikuspegiak gehitu zure azterketaren instrukzioen arabera.
## Git erabilera
Aldaketak egin ahala, commits egin maiz.
Aldaketak gorde eta bidali GitHub-era honela:
- git add .
- git commit -m "Commit mezua hemen"
- git push origin main
## Azterketa bukatu baino lehen:
- git add .
- git commit -m "Azken entrega"
- git push origin main
